# Module bloc-notes - 0.78.3-dev

## Demande

Priorite utilisateur (image « PRIORITAIRE M.A.J. 0.78.2-dev ») : « mettre la
possibilite de prendre des notes via peut-etre un petit module ou une petite
extension qui pourrait etre pratique ». Deuxieme volet du decoupage valide
(0.78.2 = anti-pub + etoile ; 0.78.3 = notes ; 0.79 = coffre).

## Ce qui a ete construit

**`NoteStore` (Models/Notes.cs, classe pure, testee)** : notes libres ou
rattachees a une page web. Champs : id, titre, contenu, URL, creee le,
modifiee le. Stockage `notes.lumora` (chiffre DPAPI, meme famille que les
favoris), format TSV percent-encode (tabulations/retours a la ligne du contenu
survivent). Horodatages tronques a la milliseconde des la creation (aller-
retour disque sans perte). Une mise a jour sans changement reel ne reecrit
rien (pas de fausse « modification » qui remonterait la note en tete). Mode
invite : notes en memoire de session uniquement.

**Panneau Notes (MainWindow.Notes.cs + XAML)** : liste a gauche (titre + date
relative + hote du site lie), editeur a droite (titre, contenu multiligne,
lien vers la page rattachee, meta creee/modifiee, suppression avec
confirmation). Recherche plein texte (titre, contenu, URL). Sauvegarde
automatique differee (800 ms apres la derniere frappe), videe immediatement
au changement de note ; pas de re-tri pendant la frappe (mise a jour de la
liste en place). Boutons « Nouvelle note » et « Note sur la page » (note
pre-rattachee et pre-titree avec l'onglet courant) + « Rattacher a la page »
dans l'editeur. « Ouvrir la page liee » navigue avec marquage explicite
(jamais re-bloque par le bouclier anti-pub).

**Integration** : entree « Notes » dans les deux menus (Donnees locales),
palette de commandes, `NotesFile` dans LumoraProfilePaths, sauvegarde/
restauration LumoraBackup (`navigation/notes.txt`), mode invite branche avec
les autres stores.

## Piege appris

`TextChanged` WinUI arrive en differe : le chargement d'une note dans
l'editeur declenchait une sauvegarde fantome (« Note enregistree. ») 800 ms
apres chaque selection. Garde ajoutee : sans changement reel par rapport a la
note affichee, aucune ecriture et aucun statut.
