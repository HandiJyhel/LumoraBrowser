## Pieges decouverts (retenir)

1. **`Dictionary<CoreWebView2, ...>` ne marche PAS** : premiere implementation
   indexee par instance `CoreWebView2` → `tracked=<aucun>` systematique dans
   `WebResourceResponseReceived` alors que `NavigationStarting` avait stocke.
   Les wrappers .NET/WinRT d'un meme objet natif n'ont pas d'identite fiable.
   → reindexation par URI + id d'onglet.
2. **Ordre non garanti** entre `WebResourceResponseReceived` (document) et
   `NavigationCompleted` : la 522 est arrivee APRES la fin de navigation lors
   du premier test, AVANT lors du second. D'ou le couplage bilateral.
3. Une erreur HTTP 5xx sur le document donne `IsSuccess=false` +
   `WebErrorStatus=Unknown` (pas de code dedie) ; `httpstat.us/522` a donne
   `ErrorHttpInvalidServerResponse` puis `ConnectionAborted` (site peu fiable
   pour tester).
