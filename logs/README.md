# Logs Pulse Browser

Ce dossier sert a conserver les traces techniques utiles pendant le developpement du projet.

Les logs peuvent aider a comprendre:

- les erreurs d'execution;
- les echecs de build;
- les problemes d'integration;
- les decisions techniques verifiees par test.

Regle importante: ne jamais stocker ici de mots de passe, tokens, cookies de session, cles secretes, donnees personnelles inutiles ou informations sensibles de l'utilisateur.

Si un log contient accidentellement une donnee sensible, il doit etre considere comme compromis et traite comme tel.
