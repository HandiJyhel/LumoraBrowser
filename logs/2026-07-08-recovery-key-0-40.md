# 2026-07-08 - Cle de recuperation locale - 0.40.0-dev

## Contexte

Deuxieme chantier prioritaire apres validation utilisateur `go` : donner une possibilite de recuperer les donnees si le mot de passe est oublie, sans casser le principe local et chiffre de Pulse Browser.

## Changements

- Version projet passee a `0.40.0-dev` dans `AGENTS.md` et `MainWindow.xaml.cs`.
- Ajout de champs de recuperation dans `UserProfile` : hash, sel, date de creation, verification et generation d'une cle `PULSE-...`.
- Creation automatique d'une cle de recuperation lors de la creation d'un profil.
- Affichage d'un dialogue de cle de recuperation avec copie dans le presse-papiers.
- Ajout d'un bouton `Creer une nouvelle cle de recuperation` dans `Parametres > Profil`.
- Ajout du lien `Mot de passe oublie ?` sur l'ecran de connexion.
- Ajout d'une recuperation du coffre dans `VaultStore` : copie de secours chiffree, cle de donnees de secours, emballage par la cle de recuperation et maintien a jour quand le coffre est ouvert.
- Lors d'une recuperation reussie, le coffre est rechiffre avec le nouveau mot de passe et le PIN est desactive pour eviter un emballage PIN obsolete.

## Verification

- Premiere tentative `build-winui.cmd` bloquee par l'acces NuGet du bac a sable (`NU1301`).
- Relance autorisee avec acces reseau : restore WinUI reussi, build WinUI reussi avec 0 avertissement et 0 erreur.
- Lancement court de `PulseBrowser.WinUI.exe` reussi : fenetre `Pulse Browser 0.40.0-dev`, processus repondant, fermeture du processus de test.
