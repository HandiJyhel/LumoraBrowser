# 2026-07-08 - Retouche Zen UI locale - 0.41.0-dev

## Contexte

Apres validation utilisateur `go`, reprise de trois points d'ergonomie : le translucide devait repartir de Pulse Explorer, le menu des trois points etait trop imposant, et les raccourcis d'accueil devaient fonctionner de maniere plus proche d'un navigateur grand public.

## Changements

- Version projet passee a `0.41.0-dev` dans `AGENTS.md` et `MainWindow.xaml.cs`.
- Ajout de `WindowTransparency` dans `UiSettings`.
- Ajout du curseur `Intensite de transparence` dans `Parametres > Apparence`.
- Port de l'approche Pulse Explorer : `WS_EX_LAYERED` + `SetLayeredWindowAttributes` en complement de `MicaBackdrop` / `DesktopAcrylicBackdrop`.
- Desactivation automatique du translucide en contraste renforce.
- Simplification du menu Pulse : retrait des entrees de gestion avancee du menu principal.
- Ajout d'actions directes sur les raccourcis de `pulse://accueil` : ajouter, modifier, supprimer.
- Branchement des messages WebView2 `newtab_add_shortcut`, `newtab_edit_shortcut`, `newtab_delete_shortcut`.
- Synchronisation des raccourcis avec `UiSettings.NewTabShortcuts` et rechargement des pages d'accueil ouvertes.

## Verification

- Premiere tentative `build-winui.cmd` bloquee par l'acces NuGet du bac a sable (`NU1301`).
- Relance autorisee avec acces reseau : restore WinUI reussi, build WinUI reussi avec 0 avertissement et 0 erreur.
- Lancement court de `PulseBrowser.WinUI.exe` reussi : fenetre `Pulse Browser 0.41.0-dev`, processus repondant, fermeture du processus de test.
