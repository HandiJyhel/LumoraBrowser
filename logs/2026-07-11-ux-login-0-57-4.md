# 2026-07-11 - Pulse Browser 0.57.4-dev

## Objectif

Corriger les retours utilisateur apres `0.57.3-dev` :

- les icones du rail vertical compact n'etaient toujours pas assez lisibles ;
- certains boutons de connexion de sites ouvraient une fenetre `about:blank` que Pulse ne raccordait pas correctement ;
- l'icone du module YouTube ressemblait trop a un telechargement de fichier classique.

## Changements

- Le rail vertical compact passe de 50 px a 60 px pour laisser une vraie zone visuelle aux actions.
- Les actions compactes `Nouvel onglet` et `Agrandir` utilisent maintenant des mini-controles encadres, avec `+` et `>>`, plutot qu'une icone trop ambigue dans une colonne etroite.
- Les boutons d'onglets verticaux compacts sont agrandis, avec une icone de site plus visible.
- Le bouton `Telecharger la video` utilise maintenant une icone de type media/video au lieu d'une icone generique de telechargement.
- La gestion WebView2 des nouvelles fenetres prend maintenant en charge les popups sans URL explicite ou `about:blank` :
  - Pulse cree un onglet de connexion ;
  - attend que le WebView2 de cet onglet soit pret ;
  - fournit son `CoreWebView2` a `args.NewWindow`.

## Limite de verification

- Le correctif de connexion cible le probleme technique typique des popups de login `about:blank`. Le site adulte mentionne par l'utilisateur n'a pas ete teste en interaction reelle avec un compte ; il faudra confirmer sur le site concerne que le bouton ouvre bien la connexion.
