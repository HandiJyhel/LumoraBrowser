# 2026-07-11 - Pulse Browser 0.57.7-dev

## Objectif

Corriger le cas ou le bouton `Connexion` ne declenche rien sur un site qui avertit que le rejet des cookies peut limiter certaines fonctionnalites.

## Cause probable

Le gestionnaire de consentement Pulse etait trop agressif :

- il emulait `__cmp` / `__tcfapi` tres tot dans la page avec un consentement "tout refuse" ;
- il cliquait ensuite automatiquement sur les boutons de refus ;
- sur certains sites, la connexion/session depend du CMP ou du choix de cookies, donc le bouton `Connexion` peut rester muet ou le flux Google peut ne jamais demarrer proprement.

## Changements

- Suppression de l'emulation precoce `__cmp` / `__tcfapi` dans le gestionnaire de consentement.
- Le refus automatique reste disponible, mais il ne clique plus que sur un bouton visible.
- Ajout d'un garde-fou : si un bandeau indique que refuser/rejeter les cookies peut limiter des fonctionnalites, Pulse ne refuse pas automatiquement et laisse l'utilisateur choisir.
- Le comportement de confidentialite reste local, mais il devient moins destructif pour les connexions.
