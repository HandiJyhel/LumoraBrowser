# Blocage silencieux des sites parasites - 0.78.3.1-dev

## Demande

Rectification demandee apres la 0.78.2 : sur certains sites agressifs, chaque
clic est detourne — l'onglet (ou un onglet neuf) part vers un site douteux
(boutiques type Temu, paris...), il faut revenir et recliquer plusieurs fois
pour naviguer. L'utilisateur ne veut PLUS VOIR ces parasites : pas d'onglet,
pas de barre, pas de question. Micro-correctif d'une version livree →
quatrieme nombre de version (regle ajoutee a AGENTS.md) : `0.78.3.1-dev`.

## Principe

**Aucun comptage de clics** : chaque tentative parasite est bloquee, une par
une, aussi longtemps que le site essaie. Le signal « site agressif » vient du
bouclier reseau : >= 3 requetes publicitaires deja bloquees sur la page
(`AdPressurePageBlockThreshold`), ou une popup ouverte a l'instant (tab-under).

## Ce qui change

1. **Nouveau fichier pur `NavigationHijackPolicy.cs`** (teste seul, comme
   PopupPolicy) : verdict de chaque navigation du document principal.
   Garde-fous dans l'ordre : adresse demandee explicitement -> jamais bloquee ;
   whitelist (origine ou destination) -> passe ; authentification -> passe ;
   domaine repertorie publicitaire -> bloque (meme sans pression) ; meme site
   racine -> passe ; cross-domaine + (pression pub OU popup recente) ->
   **BlockParasite**. L'ancienne logique dispersee dans MainWindow.AdShield
   (strict block + tab-under) est absorbee dedans.
2. **Popups durcies** (`PopupPolicy`) : sous pression publicitaire, toute
   popup cross-domaine (et `about:blank`, support du document.write pub) est
   bloquee NET — plus d'ouverture en arriere-plan (le verdict
   `AllowInBackground` de la 0.78.2 disparait au profit de
   `BlockUnderAdPressure`). Popups meme site et fenetres de connexion
   inchangees.
3. **Silence complet** : la barre « Continuer quand meme » est supprimee
   (XAML + handlers + mecanique `AllowAdContinue` du tracker). Les blocages ne
   produisent que la ligne de statut et le compteur du bouclier. Recours :
   taper l'adresse (explicite, jamais bloquee) ou whitelist par site.

Limite connue et assumee : certains sites detectent que leur pub n'est pas
partie et refusent de fonctionner (« desactive ton adblock ») ; la whitelist
par site reste la soupape.

  mecanique).
- Builds Debug + Release : 0 avertissement / 0 erreur.

  usage reel sur les sites concernes.
