# Coque WinUI 3 0.8.0-dev

## Contexte

L'utilisateur a recadre le projet: l'interface cible etait WinUI 3 depuis le depart, et la coque Win32 ne doit pas devenir l'interface produit.

## Changements

- Passage de la version projet a `0.8.0-dev`.
- Ajout de `PulseBrowser.WinUI`, une premiere application WinUI 3 C# separee du prototype Win32.
- Ajout de `run-winui.cmd`, `build-winui.cmd`, `scripts/run-winui.ps1` et `scripts/build-winui.ps1`.
- Ajout de `docs/WINUI3_MIGRATION_0_8.md`.
- Mise a jour de `AGENTS.md`: Win32 est desormais marque comme prototype historique, WinUI 3 comme direction produit.

## Etat

La coque WinUI 3 contient une premiere structure d'accueil, centre local et parametres. Le moteur CEF/Rust n'est pas encore raccorde.

## Verification

- Restore NuGet Windows App SDK reussi apres autorisation reseau.
- Build WinUI 3 reussi avec MSBuild Visual Studio x64.
- `cargo fmt --check` reussi.
- `cargo test` reussi: 50 tests passent.
- `cargo build` reussi en `0.8.0-dev`.
- Lancement automatise de `PulseBrowser.WinUI.exe` tente: le processus demarre, mais aucune fenetre top-level n'est detectable dans cette session. Le processus de test a ete arrete.
