# Icône de mode et accueil Équilibre 0.83.4-dev

Cette étape corrige deux points d'ergonomie relevés après l'ajout des modes
d'usage.

## Accueil Équilibre

Le mode `Équilibre` ne doit pas afficher de raccourcis artificiels. Il conserve
une page d'accueil sobre : identité Lumora, capsule de mode, recherche et vrais
raccourcis utilisateur uniquement.

Les cartes d'avantages restent réservées aux modes spécialisés :

- `Focus`
- `Lecture`
- `Création`
- `Recherche`
- `Nuit`

## Icône permanente de mode

Un bouton permanent `Mode d'usage` est ajouté dans la barre principale, à côté
des modules Lumora.

Ce bouton :

- reste visible en permanence ;
- affiche une icône qui change selon le mode actif ;
- ouvre un sélecteur rapide des modes ;
- applique le mode immédiatement ;
- synchronise les réglages `Mon Lumora` et `Modules Lumora` ;
- rafraîchit les pages `lumora://accueil` ouvertes.
