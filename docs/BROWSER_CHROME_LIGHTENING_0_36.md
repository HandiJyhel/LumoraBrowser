# Chrome navigateur allege (0.36.0-dev)

Ce palier poursuit la passe visuelle apres comparaison avec une capture de Google Chrome.

Objectif: faire disparaitre l'impression d'application WinUI composee de bandes empilees, pour rapprocher Pulse Browser d'une surface de navigation plus unifiee.

## Changements

- La bande superieure `Pulse` separee n'est plus affichee.
- Les commandes utiles de cette bande sont replacees dans la barre de navigation.
- La title bar Windows est neutralisee en sombre afin d'eviter la grande bande orange.
- La barre d'adresse prend une forme plus arrondie et plus lisible.
- Le statut permanent en bas disparait quand la page web est visible.
- Le pied de fenetre reste disponible uniquement dans les panneaux internes pour proposer le retour a la page.
- L'accueil `pulse://accueil` devient une page de nouvel onglet plus simple: marque, recherche centrale et raccourcis legers.
- Les cartes produit de l'accueil sont retirees de cette surface quotidienne.

## Direction

Pulse ne doit pas copier Chrome, mais il doit apprendre de sa discretion: les commandes du navigateur doivent etre accessibles sans prendre le dessus sur la page.
